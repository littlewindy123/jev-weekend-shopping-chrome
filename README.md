# JEV 双休购 · Chrome 插件版

**把对双休的支持，带进每一次购物。**

逛淘宝、京东时，让 JEV 帮你猜一猜商品背后的工作制：**疑似非双休，直接在商品图上盖一个 PASS。**

不用来回复制商品，不用切换聊天窗口。照常浏览，边逛边判断。

> 一个表达消费偏好的 AI 实验。印章始终标注「AI 猜测 · 未核实」，不代表商家的真实用工制度。

## 它能做什么

- **在商城原页盖章**：印章落在原商品图上，保留原有排序和点击。
- **滚动到哪，判断到哪**：识别进入视口的商品，支持动态加载和翻页后的新卡片。
- **只有两个结果**：猜测非双休 → 盖 PASS；猜测双休 → 保持原样。
- **有店看店，没店看产品**：优先参考公司、店铺，其次品牌、制造商，最后按产品和品类猜测。
- **看得到运行状态**：显示识别数、判断数、盖章数和不盖章数，失败单独提示。
- **无需下载本地模型**：直接使用 TypeSafe 官方 JEV，填写自己的 API Key 即可。

当前版本 **0.4.3** · Chrome Manifest V3 · MIT 开源。

## 安装：下载 → 加载 → 开启

1. 点击仓库绿色 **Code → Download ZIP**，解压到一个固定文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 在 [TypeSafe 控制台](https://console.typesafe.ai/keys) 获取自己的 API Key。
5. 打开「双休购物」扩展，填写 Key，点击「保存并测试连接」，再开启开关。
6. 刷新京东或淘宝商品列表，向下滚动。左下角会出现运行统计。

日常使用不需要 Node.js、npm 或构建步骤。更新时用新版文件替换原目录，点击扩展的重新加载，再刷新商城页；官方 Key 和开关会保留。

## 判断是怎么来的

```text
可见商品卡片
  ↓ 读取标题、店铺、品牌、简短描述
TypeSafe 官方 JEV
  ↓ 在“非双休 / 双休”中选择更可能的一项
非双休 → 原图盖 PASS     双休 → 保持原样
```

请求中只有六个白名单字段：`platform`、`product_id`、`product_title`、`shop_name`、`brand_name`、`shop_description`。缺失字段留空。

当前版本处理的是**文字**：不会把商品图片发给模型，也没有联网搜索企业排班资料。公司和品牌线索来自卡片本身。单休、大小周归入非双休；信息有限时依然按产品线索作二选一猜测。

## 几个需要说清楚的地方

**这是猜测，不是企业认证。** 商品标题不能证明员工是否双休；印章可能误判，没有印章也不代表商家已被核实为双休。请把它当作表达偏好的浏览辅助。

**开源免费，官方 API 按账户规则计费。** 扩展不收取订阅费；使用 JEV 消耗你自己的 TypeSafe 额度。赠送额度、价格与可用权限以[官方说明](https://docs.typesafe.ai/models)为准，不承诺无限免费。

**商品文字会发送到 TypeSafe。** 扩展不采集 Cookie、订单、聊天记录或整页 HTML。Key 保存在浏览器本机扩展存储中，仅由扩展后台发给固定官方接口；不要把自己的 Key 写进源码或提交到 GitHub。

**适配有范围。** 当前配置支持京东首页、搜索/列表，以及淘宝首页/搜索页。京东首页和新版搜索的真实结构已核对；淘宝真实页面的完整流程仍待验证。网站改版可能影响识别，商品详情页和所有活动页并非都支持。

## 开发与验证

运行扩展无第三方运行时依赖。开发测试需要 Node.js 22+。

```bash
npm test

# 浏览器回归：安装开发依赖及测试浏览器
npm install
npx playwright install chromium
npm run test:browser
```

- 42 项单元检查：请求格式、二选一、权限、Key 保存、缓存、限流、取消与错误处理。
- 25 组浏览器检查：MV3 加载、设置交互、原商品节点保留、印章点击穿透、滚动、动态卡片与状态统计。
- 官方接口另做 6 个样本实测：单休、双休、大小周控制样本符合预期，3 条仅标题输入均返回有效二选一结果。

浏览器回归使用模拟商品与响应；官方接口样本验证分类行为，**不是商家作息准确率评测**。`demo.html` 是明确标注模拟结果的开发诊断页，日常使用请直接打开商城。详见 [测试范围](docs/TESTING.md)。
